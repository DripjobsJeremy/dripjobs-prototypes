Fixing the jumbled mobile section list

On mobile, the proposal builder's section list (Hero Image, Trust Builders, Client Notes, About Us, etc.) squeezes the title and description into a column far narrower than the row has room for, so text breaks one word per line. The fix gives that column its full share of row width and truncates a too-long title or description on one line with an ellipsis instead of wrapping, the same pattern already used by the Misc Documents list on the same settings page.

Root cause
The row's text column was constrained to a fixed width far smaller than the space actually available next to the drag handle, position number, and icon — so both the title and description wrapped one word per line instead of using the row's full width.

What changed

  • Text column now takes the row's remaining width instead of a fixed narrow width.
  • Title truncates to a single line with an ellipsis if it's too long for the row, instead of wrapping.
  • Description truncates the same way, matching the Misc Documents list's filename truncation on the same settings page.
  • Drag handle, position number, and icon keep their fixed sizes — only the text column's width behavior changed.
