Google Calendar OAuth Feasibility on Mobile App Ready for Dev
Mobile currently hides Google Calendar sync entirely, since authenticating from the in-app embedded browser throws an error. This investigation confirms the actual root cause and determines whether launching the OAuth flow in the native system browser (Safari/Chrome) instead of an embedded webview would let it succeed, before any UI or build work is scoped.
🔔
Drip Preference Visibility (Command Center & Proposal Builder) Needs Design
Locks the Deal-level "Disable Drips" toggle when a Contact has opted out at the contact level, and adds a reminder wherever a Stage or Drip Sequence change is about to reactivate drips (Move, Change, Send Proposal, Approve Without Signature), or carries the disabled state forward when the stage move is API-initiated. The one piece still pending Design: the Deal card's visual indicator for that carried-over state.
📦
Save & Reuse Packages in Proposal Builder Needs PM Analysis
Save proposal packages and reapply them in future proposals — huge time saver for repeat job types. Navigation placement, the two-step preview-then-insert selection flow, and the editor's fields were all decided in the May design pass; ticket is queued for PM analysis before scoping resumes.
🏷️
Multi-Discounts on a Proposal Needs PM Analysis
Applying a second discount today overwrites the first instead of stacking, forcing users into manual negative line items that need recalculating by hand. This would let multiple named discounts stack on a single non-package proposal, each its own line item. One open item blocks scoping: whether percentage discounts should recalculate when a customer toggles an optional item in the Customer Portal, pending a call from Tanner or Jason.
🖼️
Add MMS (Image Attachment) Support to Drip Text Steps Needs PM Analysis
Lets a Text Message drip step include an attached image (e.g. a photo of the assigned salesperson) and send as MMS. Twilio numbers are confirmed MMS-capable, but whether the current A2P 10DLC campaign registration covers media, MMS pricing versus SMS, and whether the messaging library can handle images are all still open questions pending verification.
👍
Thumbtack Direct Lead Integration Need More Context
Real-time lead import from Thumbtack directly into the DripJobs pipeline. Previously reported as in progress on staging credential setup; status has since moved to "Need More Context," meaning something in scope or the API details needs clarifying before dev continues. Worth a direct check-in with Terry/Michael on what's blocking.

Proposal Expiration Date Enforcement & Re-Open Flow Needs PM Analysis
Makes the existing expiration date field actually mean something — blocks customer signing and contractor edits once expired, with a Re-Open flow that mirrors the rejected proposal pattern.
🧾
Smart Invoice Due Dates: Net Terms & Progressive Portal Banners Needs PM Analysis
Adds company-level default payment terms (Net 7/15/30/Custom), quick-select date chips in the due date picker, and a progressive customer portal banner (informational → due soon → overdue) instead of today's all-or-nothing red overdue state.
📬
Invoice Reminders Needs PM Analysis
Extends the existing Reminders page with a new "For Invoices" section (before/on/after due date, email + SMS), plus a redesigned Invoices page with summary stats, filters, a Reminders status column, and bulk actions.
