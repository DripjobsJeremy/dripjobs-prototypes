Dev notes for this screen

  • BR1 (section cards): toolbar and table live in one .settings-section; Add/Edit opens a slide-over drawer.
  • BR2 (floating labels): Name, Description, Cost Type and Amount are floating-label fields; Amount uses the "$" prefix field group.
  • BR3 (buttons): "Add Misc" and "Save" are btn-primary, "Cancel" is btn-outline-primary, "Yes, delete it!" is btn-danger.
  • BR5 (toggles, tags): "Show Inactive" and the drawer's "Active" use the Switchery pattern (.switchery hook kept, #8B85EA); Active/Inactive are status tags.
  • Copy fixes: "Desription" to "Description" in the table header, and "Employee not deleted." to "Misc cost not deleted." in the cancelled dialog.
  • Seed data: "Dump Fees" is a demo-only inactive row so "Show Inactive" has something to reveal.
  • Drawer vs. modal: Add/Edit is a non-dimmed drawer and the delete dialogs use a dimmed backdrop, both matching production. Neither pattern is documented in the design system yet.
  • Design system gap (not blocking): btn-danger / btn-success have no documented hex values; a standard red/green pair is used.
  • Accessibility: dialogs use role="dialog" aria-modal="true", Escape closes, focus returns to the triggering row button, and icon buttons name their row.
