Dev notes for this screen

  • BR1 (section cards): header, token-expired message, filters, table and empty-state banner sit in one .settings-section.
  • BR2 (floating labels): the placeholder-only fields now have real floating labels: Name, Dates, Status.
  • BR3 (buttons): "Clear" is btn btn-outline-primary, "Filter" is btn btn-primary.
  • BR5 (alert): the "Import your employee timesheets" message uses .settings-alert--warn.
  • BR6 (tokens): the production Filter button used a legacy purple; it now uses var(--st-color-primary).
  • Shell: built as a full page with the standard chrome. Production screenshots didn't show the chrome around it, so confirm it isn't a modal during dev.
  • Accessibility: the expired-token message uses role="alert"; column headers render even with no rows.
