Dev notes for this screen

  • Nav: breadcrumb returns to Reports; the employee name opens that employee's Employee Timesheets Report.
  • BR1 (section cards): filter, report header and table share one .settings-section, same structure as the Timesheets report.
  • BR2 (floating labels): Pay Period is a floating-label select. There is no Employee filter on this report (it rolls up all employees).
  • BR3 (buttons): "Go" is btn btn-primary, "Download CSV" is btn btn-outline-primary (toast only).
  • BR6 (tokens): colors scoped to #job-costing-payroll-page.
  • Fix: the breadcrumb previously read "Employee Timesheets" on this page; corrected to "Employee Payroll Report".
  • Accessibility: semantic table with scope="col" headers; OT values are bold as well as colored.
  • Clean view (prototype-only): the "Hide callouts" button in the top bar hides the demo banner, orange BR/Flag chips and these dev notes on all 8 screens, for an unobstructed look at what an end user would see. It remembers your choice as you navigate between screens.
