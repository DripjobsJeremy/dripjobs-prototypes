Jobs Schedule Calendar — Crew Leveling

Prototype for ticket 86barp4zu. Jobs on the Day, 3 Day, and Month views are grouped and ordered so each crew consistently appears in the same relative position, matching the crew order in Crew Settings, instead of stacking by start time. Use the controls below to compare the current behavior against the proposed fix, and to see what happens when a crew's position changes.

ℹ️
Assumption carried from the ticket
Sort order within a single crew's own jobs on the same date (currently by start time) is unchanged. This prototype only reorders crews relative to one another, not jobs within a crew.
⚠️
Open gap, flagged for engineering scoping
Behavior for jobs whose crew has since been deactivated or deleted in Crew Settings is not defined yet. This prototype does not simulate that case — recommend walking it in production before finalizing.
Prototype control, not production UI
Day 3 Day Month
Crew Settings — Display Order
Reference of each crew's position in Crew Settings. Reorder here to see the calendar update automatically — no separate calendar configuration needed. Only affects "New: crew leveled" sort.
Jobs with no crew assigned always sort to the bottom of each date's list, below all crew-ordered jobs, regardless of this order.
Acceptance criteria coverage
How this prototype demonstrates each acceptance criterion from the ticket.
✓Day view groups and orders jobs by crew, matching Crew Settings — switch to the Day tab with "New: crew leveled" selected.
✓3 Day view groups and orders jobs by crew, with the same crew in the same relative position across dates — see the 3 Day tab; each column follows the same crew order.
✓Month view groups and orders jobs by crew using a layout scaled to the smaller cell size — see the Month tab; compact colored-dot lines replace full swimlane cards.
✓Crews with no jobs on a date show no row/placeholder — no empty rows are ever rendered; the Day view also calls out which crews aren't scheduled that day.
✓Unassigned jobs sort below all crew-ordered jobs, no dedicated label — see any date with an "Unassigned" job in "New: crew leveled" mode.
✓Reordering a crew in Crew Settings updates the calendar automatically — use the ▲/▼ buttons in the Crew Settings panel above.
