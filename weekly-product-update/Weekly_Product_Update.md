# DripJobs Weekly Product Update

**Period:** November 7 – November 11, 2026
**Release:** Nov 9 deployment · 4 updates

---

## Communications

### Fixed Email Blast Subject Line Emojis Lost on Save (*Nov 9*)
**What changed:** Fixed a bug where emojis typed into an email blast's subject line displayed correctly while typing, but were replaced with "??" everywhere the subject appeared after the blast was saved or sent, including the subject field, Live Preview, test sends, and recipient inboxes. Emojis in the blast body were never affected.
**Why it matters:** Blast subject lines with emojis now save, send, and display exactly as entered.
**Action needed:** If a blast saved before this fix still shows "??" in its subject, re-enter the emojis and save again; it won't be corrected automatically.

## Proposal Builder

### Added Description Only Option to the Add Multiple Items Modal (*New · Nov 9*)
**What changed:** You can now mark items as Description Only while adding them in bulk through Add Multiple, on web and mobile. Marking an item Description Only locks its Qty, Price, and Optional fields, and it displays and behaves exactly like a Description Only item set up through the single line item editor, in proposals, packages, and proposal templates.
**Why it matters:** You no longer have to add items in bulk and then open each one individually to turn on Description Only.
**Action needed:** None

## Production Rates

### Added Paint Pro Base Rates to the Production Rates Default Seed (*Nov 9*)
**What changed:** Companies adding the Production Rates add-on for the first time now get an expanded set of default categories, substrates, rates, and products, combining the existing defaults with an industry baseline rate set. Companies that already have the add-on are unaffected.
**Why it matters:** New Production Rates users start with more realistic, ready-to-use pricing before customizing anything.
**Action needed:** None

---

## Branding

### Added a Full Logo Upload That Supports Wide Logos (*New · Nov 9*)
**What changed:** Added a new optional "Full Logo" upload in Company Settings > Brand, alongside your existing square logo. Wide or horizontal logos now display in their true proportions on your Customer Portal sidebar, on Proposal, Invoice, and Work Order documents and PDFs, and in outbound emails, instead of being squeezed into a square.
**Why it matters:** Companies with wide or horizontal logos no longer see them shrunk until unreadable.
**Action needed:** None
