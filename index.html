Link Multiple Google Calendars
Clickable prototype for the calendar connection screen supporting more than one linked Google Calendar per account, shown in the real entry-flow context: Appointments (Sign in with Google) → choose calendars to link → Success → back to Appointments with a live connected summary and a Manage link. Linked calendars are visible in DripJobs for reference only; the user designates exactly one as the write-to calendar that new DripJobs events are copied to, and can change that designation anytime without moving previously synced events. Demonstrates the unlink edge case: unlinking the current write-to calendar while others remain linked requires picking a new write-to first, unlinking it when no other calendars remain linked is a full disconnect. Scoped to desktop/web only per the ticket (mobile linking is a separate track).

Send Marketing Agency Info
Clickable prototype for a new "Send Marketing Agency Info" component on the Zapier card in Company Settings > Integrations. Clicking it opens a copy-only compose view pre-filled with a template that auto-fills the user's name, company name, and Zapier API key, leaving the agency contact name as an editable placeholder. A single Copy button copies the full subject and message with a "Copied!" confirmation; there is no send, reply-to, or BCC functionality. Includes scenario toggles for the two open edge cases flagged in the ticket: incomplete profile info (falls back to bracketed placeholders) and no Zapier API key yet (button disabled with a prompt) — both flagged as assumptions needing confirmation before dev.
