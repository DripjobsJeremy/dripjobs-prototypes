Holiday Calendar — Independent Per-Calendar Controls

Prototype for ticket 86bbrazc3, a follow-up to 86bbc0rvr. The Holiday Calendar preference (None / United States / Canada / United States & Canada) moves out of User Profile entirely. Each calendar, Appointments and Job Schedule, now has its own independent control: changing one has no effect on the other. This supersedes the original ticket's BR-2 (single per-user setting) and BR-8 (one control governs both calendars).

ℹ️
Migration at rollout (BR-8)
This demo user previously had United States & Canada selected in User Profile. At rollout, that single value seeds both the Appointments and the Job Schedule preference below. From here forward the two are independently editable, try changing one and confirm the other doesn't move.
Before / after: User Profile (BR-1)
The preference no longer lives in a shared location. It's now set from within each calendar.
