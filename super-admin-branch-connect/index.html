How to use this prototype

1. Start from Tenants
This is the Super Admin nav as it exists today, with Tenants active. There's no standalone "Branches" item; the connect flow lives inside Tenants, per the ticket's Access Point.
2. Two entry points, one flow
Click Connect Branches in the top-right to start unscoped (search picks the Parent Account). Or click the ⋮ menu on any tenant row and choose Connect Branches to jump in with that account pre-selected as Parent.
3. Try the duplicate block
In the branch search step, type "sunrise": Sunrise Coatings is already a branch of Coastal Painters Group, so it appears disabled with a tag instead of being selectable.
4. Add multiple, then confirm
Add more than one branch before confirming, remove one you added by mistake, then click Connect Branches. A toast confirms the connection and the auto-sync of Branch Admin access.
5. View an existing group
Click the purple "Parent · 2 branches" pill on Coastal Painters Group's row to see existing connections and a sample of the ongoing access-sync log.
6. See the failure state
Check "Simulate failure" in the demo control before confirming to preview the notification shown if Branch Admin sync fails (Edge Case / AC10). That control only exists in this prototype.
