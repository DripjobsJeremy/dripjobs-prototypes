Developer notes (changed parts only)

What changed

  • Added one element directly to the right of the existing "Text Messages Are Disabled" badge, inside the same header row. The badge's size, color and text are unchanged.
  • Users with Company Settings access see a Complete Setup button. Reuse the Text Messaging card's Complete Setup button class at btn-sm size (30px tall, 8px radius) so it fits the 57px header.
  • All other users see the plain, non-clickable text Ask your admin to finish setup in the header's existing text color, 11px, wrapping to two lines to match the badge. No button is rendered for them.
  • Wrap the badge and the new element in one flex group (gap: 8px) so they read as one unit and wrap together.

Click behavior

  • From any page, Complete Setup goes to Company Settings > Integrations and opens the existing Text Messaging setup form on arrival (for example via a query flag the Integrations page reads on load). It must not just land on Integrations.
  • The form is the same one the card's Complete Setup button opens. CAD accounts rely on the Nov 12 CAD fix and should reach the same form without error.

Narrow web widths

  • When there isn't room beside the badge, the button or message wraps below it (column direction, left aligned). It is never hidden, ellipsized or moved into a menu.
  • The header grows to fit the wrapped row (about 95px). In this prototype the search field and user name hide at narrow widths only to make room; match whatever production already does there. Engineering to confirm the taller header doesn't overlap fixed-top content.
