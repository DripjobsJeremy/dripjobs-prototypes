What this prototype demonstrates

  • BR-1 — Link more than one Google Calendar from this screen.
  • BR-2 — All linked calendars' events are for reference only; they don't affect scheduling availability.
  • BR-3 — Exactly one linked calendar is the write-to calendar at a time.
  • BR-4 — Linking a calendar never auto-assigns it as write-to, that's a separate action.
  • BR-5 — Changing the write-to calendar only applies to new events going forward. Previously synced events aren't moved.
  • BR-6 — Unlinking the current write-to calendar while others remain linked requires picking a new write-to first. Unlinking it when no other calendars remain linked is a full disconnect.

Ticket 86bbkb1vp scopes this to the desktop/web calendar linking flow only (V1). Mobile linking is a separate, unresolved track. The Appointments page header and the "Continue to Appointments" / "Manage" entry points are this prototype's own connective tissue, not pictured in the ticket, added to show the real flow context from the provided screenshots.
